# What is this?
This is my second program I've ever written in C#, as a learning exercise. I never actually wrote a
calculator program before, not even a really basic dumb one, so I figured I'd try it. It's probably
really overbuilt by now, but I care about making my stuff high-quality.

This program features:
* Basic arithmetic; add, subtract, multiply, divide, and basic order of operations
* Fault-tolerant parser that tries to be verbose and helpful with syntax errors
* Primitive support for functions (only 1-argument built-in functions for now, but will extend to
  more than that)
* Support for some constants like Pi and e

This is ultimately a toy project to help me get more comfortable with bot C# and doing parsers and
lexers, since I'm not great at either of those. :3
